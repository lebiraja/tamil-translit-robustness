\label{sec:method}

\textbf{Models.}
Both models are character-level, with separate source and target vocabularies built from the training data (30 and 52 symbols including specials).
The BiLSTM has a two-layer bidirectional encoder, a two-layer LSTM decoder and Luong ``general'' attention~\cite{luong2015effective,bahdanau2015neural}.
The Transformer is a pre-LN encoder-decoder with three layers per side, four heads and learned positions~\cite{vaswani2017attention}.
Width is chosen to hit about 1M, 3M and 8M trainable parameters: BiLSTM 0.98M, 2.99M and 8.04M; Transformer 0.80M, 3.15M and 8.70M, so ``matched'' means approximately matched.

\textbf{Training, tuning and decoding.}
Adam with gradient clipping at 1.0 and early stopping on development CER (patience 6 during tuning).
For each architecture and size we run 20 random-search trials over learning rate ($10^{-3.5}$ to $10^{-2.5}$), batch size (64--512), dropout, label smoothing (0--0.1) and, for the Transformer, warmup, selecting on development CER with beam 10 only; the test set is never used for selection.
Decoding uses beam search with beam 10, which yields an $n$-best list.

\textbf{Metrics.}
CER is the corpus-level Levenshtein distance over code points between the top hypothesis and the closest attested reference, divided by the reference length~\cite{roark2020dakshina,kirov2024context}.
Top-$k$ accuracy counts an input correct if any of the best $k$ hypotheses equals any reference, and mean reciprocal rank (MRR) uses the rank of the first correct one~\cite{chen2018news}.

\textbf{Augmentation conditions.}
A0 uses Dakshina only.
A1 adds random character noise (deletion, insertion, substitution, swap)~\cite{karpukhin2019training}.
A2 adds the four Tamil-phonological operators V-DROP, V-LEN, GEM and DIGRAPH.
A3 adds the 123{,}488 sampled back-transliterations~\cite{sennrich2016backtranslation}.
A4 combines A2 and A3.
CTRL adds the same pool words romanized once, greedily, and so separates ``more words'' from ``more spelling variety''.
Online noise is re-drawn every epoch and leaves 40\% of items clean.
Two held-out variants, A2-noGEM and A2-noVDROP, omit one operator in training and are tested on it.
Keyboard noise (KEY) and stretching (REPEAT) are deliberately absent from A2, so they test transfer.

\textbf{Statistics.}
Each cell is the mean and sample standard deviation over five seeds.
System pairs are compared with a paired bootstrap over test items (10{,}000 resamples, seed-averaged item errors) and the six C2 conditions with Kruskal--Wallis and Dunn's test with Holm correction on per-seed CER.
With five seeds the seed-level tests have little power, and the item bootstrap describes the test set rather than the population of trainings; we state this where it matters.
